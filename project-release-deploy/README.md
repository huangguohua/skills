# Project Release Deploy

通用项目发布部署 Skill，在代码审查全部关闭且测试通过后执行标准化发布流程。

## 快速开始

1. 确保 `REVIEW_REPORT.md` 中无"待修复"条目
2. 确保 `test-report.md` 中测试全部通过
3. 触发本 Skill（关键词：发布 / 部署最新版本 / 更新线上环境 / 重启服务）
4. 确认部署计划后执行发布

## 核心原则

- **闸门严守**：REVIEW_REPORT 有未关闭问题或测试未通过时，绝不部署
- **备份先行**：任何部署前必须完成备份
- **冒烟必做**：部署后必须执行冒烟验证
- **失败即回滚**：冒烟验证失败立即触发回滚流程
- **日志可追溯**：每次部署都产出完整的部署日志
